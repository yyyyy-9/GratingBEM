# 数值设置与适用范围

## 物理模型

裸界面求解器处理二维周期、沿槽线不变的 TE/TM 散射，空气位于上方，均匀材料位于下方，时间约定为 `exp(-iωt)`。计算采用 KM1 型双密度周期边界积分方程、Ewald 准周期 Green 函数及 Nyström 离散。

裸界面材料不自动包含氧化层、镀膜或粗糙度。单层介质膜通过独立的 [实验性涂层接口](coating.md) 显式启用。多层膜、三维锥形入射、通用 RCIP 和严格全局误差上界不在当前支持范围。

## 数值设置

| 设置 | 作用 |
| --- | --- |
| `p_order` | 面元上的 Nyström 求积与插值阶数 |
| `max_panel_wavelengths` | 面元长度控制，减小可加密空间网格 |
| `modes_air` / `modes_metal` | 两种介质的周期核截断设置 |
| `oversample` | 近奇异积分的过采样设置 |
| `max_nodes` | 节点上限，防止无意触发过大计算 |

对关键参数点分别改变网格、阶数和核截断，比较目标级次及全部传播级次。尖角、细圆角和深槽金属 TM 通常需要更细的独立收敛检查。相邻两次结果接近并不自动给出绝对误差上界。

## 结果解释

效率相对于入射功率定义。空气侧不传播的级次没有远场功率。总反射率、小矩阵残差和可选的空气侧能流检查可用于诊断；它们不能单独证明全部界面条件和离散精度。

接近 Wood / Rayleigh 截止时数值性状可能恶化，精确截止会明确拒绝。需要与已知物理结果比较时，可选择平面 Fresnel 解、无介质差异极限或条件一致的独立计算。

Newport 示例的结构、材料来源和建模假设见 [参数说明](newport79.md)。
