# 误差控制与已知物理限制

## 能算什么

二维周期、沿槽线不变、空气上半空间—均匀材料下半空间的 Maxwell TE/TM 散射。求解器使用 KM1 型双密度周期传输积分方程（Kleinman–Martin 类）、Ewald 准周期 Green 核、Nyström 产品积分与几何分级面元。

**当前不支持：** 涂层、氧化层、多层、三维锥形入射、狭义 Wood anomaly 的鲁棒处理、已验证通用 RCIP、全局误差严格上界。铝使用 Rakić Lorentz–Drude 的体光学常数，它不必代表真实沉积薄膜/氧化层的折射率。`eps` 的符号按 `exp(-iωt)`。

## 怎样判断结果可信

1. **基础检查**：目标级次在空气侧传播；矩阵残差不是 NaN；总反射率不大于 1（否则被动材料物理上不可能）。
2. **网格独立性**：减小 `max_panel_wavelengths`，使更多节点落在边界；比较目标级次和全部传播级次。只看相邻两级差异可能误判。
3. **积分阶数独立性**：同一面元布局提高 `p_order`（例如 4 到 6），避免把几何加密和密度插值误差混为一谈。
4. **核精度独立性**：提高 `modes_air/modes_metal` 和 `oversample`；特别注意近奇异面元和临近 Rayleigh 阈值。
5. **独立物理基准**：平面界面的 TE/TM Fresnel、理想 PEC 反射守恒、必要时高精度 RCWA/FMM 和实验数据。

**重要：** 只有 `reflection_sum <= 1` 不能证明效率准确；当前包的 `Calculation.diagnostics` 中没有独立、严格积分得到的金属吸收（旧研究代码部分版本测试过通量）。对于实际金属，未报告的反射功率可由吸收解释，但不能把 `1-R` 当作独立数值验证。

## 接近异常与密集尖角

`Wood/Rayleigh` 阈值附近准周期 Green 表述数值性状会恶化；当前实现主动拒绝某些奇点。小半径圆角、长槽面、金属 TM 场或紧邻边界段均需独立加密。圆弧即使几何表示解析，也不意味着积分密度具有足够分辨率。

## 对参考效率的解释

79 线/mm、74° 中阶梯在 248.33 nm、−98 级 Littrow 下，既有研究型模型得出约 TE 67%、TM 64%。该数字依赖采用的 90° 顶角、20/50 nm 圆角和裸铝材料模型，**不是** Newport 官方绝对效率，也不是当前包的新测量结果。请先完成独立收敛及材料/槽形参数一致性检查。

## 误差的三个层次

- **几何/材料建模**：真实槽型、粗糙度、氧化层是否等于假设，不能靠网格加密修复。
- **数值离散误差**：Nyström 阶数、面元大小、近奇异积分、周期核截断；需系统收敛分析。
- **算法与方程限制**：周期奇点、矩阵病态与未覆盖物理模型；不是自动加密必然解决的问题。
